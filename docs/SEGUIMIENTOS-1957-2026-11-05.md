```json
{"shipments":[{"tracking":"CODIGO_EJEMPLO","recipient":"NOMBRE DE EJEMPLO","postal_code":"00000","status":"recogido","street":"CALLE DE EJEMPLO"}]}
```

Los estados admitidos son `recogido` y `pendiente`. El script valida nombre y código postal, vínculo con la tienda 1957, unicidad del pedido, ausencia de una nota pública previa de seguimiento y validez del correo del comprador. Exige que al menos dos notas anteriores corroboren el mismo texto de referencia antes de enviar notas de pedidos recogidos. Para los pendientes no debe afirmar que el transportista ya recogió el paquete.

Los registros de notificaciones creadas se guardarán en una opción privada de WordPress (`mdo_1957_tracking_20261105_ledger`), con el pedido, código, ID de nota, fecha y texto enviado. Un ID de nota indica creación de la nota; la entrega efectiva de un correo exige comprobar además los registros del sistema de correo.
