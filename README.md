# El Mercado de Origen — Child Theme

Repositorio del tema hijo de WordPress para la renovación visual de [El Mercado de Origen](https://www.elmercadodeorigen.com/).

## Estructura

El tema instalable se encuentra en `elmercadodeorigen-child/` y utiliza **Woostify** como tema padre.

## Flujo de trabajo

1. Crear una rama a partir de `main`.
2. Abrir un pull request.
3. Validar PHP y la estructura del tema mediante GitHub Actions.
4. Al fusionar en `main`, desplegar automáticamente al entorno de desarrollo cuando estén configurados los secretos del entorno `staging`.

Consulta [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) para configurar el despliegue.
